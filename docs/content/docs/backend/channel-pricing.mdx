## 积分面值和毛利

RightMovie 按 **1 元 = 100 积分**核算。先在「后台 → 用户分组」设置人民币兑换比例。以积分计价的模型直接填积分；以 CNY 计价的模型填写元，由系统换算一次。核对全局、分组和模型倍率，折扣会影响实收和毛利。

成本积分 = 人民币成本 × 100。目标毛利率为 25% 时，整数售价 = 向上取整（成本积分 ÷ 0.75）。实际毛利率 =（实收积分 − 实际成本积分）÷ 实收积分。例如成本为 72 积分，售价应为 96 积分。成本乘以 1.25 只得到 20% 毛利率。

## 建档和复核

1. 按渠道、模型、操作和规格建立价格档。按次收费的上游按一次成功请求计量；四宫格可对应一次请求。按 Token 收费的上游分别核算文本、图像、缓存等计费项。
2. 用同一密钥、时区、小时、模型和计费项核对上游账单与调用日志。先汇总用量，再按供应商账单的精度和取整规则核算。小时账单无法精确分摊时，逐次金额标记为估算。缺少分类的输出 Token 不宜直接按图像单价结算。
3. 在「后台 → 系统渠道 → 渠道模型 → 价格档」分别填写成本与售价。图片按张或按次结算时，使用对应规格的预算成本，按真实账单定期校准。高分辨率、不同质量或其他操作另行取样，未核价的规格不使用通配低价。
4. 先通过模型报价核实默认规格、数量和分组倍率，再开放使用。按账期计算实际毛利：（该账期实收积分 − 上游实际成本积分）÷ 实收积分；历史订单以创建时的价格快照为准。

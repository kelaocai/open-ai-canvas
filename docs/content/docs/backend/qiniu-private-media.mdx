## 故障现象和定位

图片已经成功上传到七牛，应用内可以显示，新标签打开却触发下载。排查时分别确认了数据库中的存储厂商、文件 MIME 类型、实际访问域名和响应头。

本次文件类型为 `image/png`，访问使用七牛 S3 默认域名，响应带有 `Content-Disposition: attachment`。七牛对默认访问域名实施强制下载策略，在线预览需要配置自定义域名。连接测试通过后，还需要单独验证浏览器预览。[七牛访问域名安全策略](https://developer.qiniu.com/kodo/13421/safety-visit)

## 空间和域名规划

生产素材使用独立私有空间，配置应用专用的对象前缀及 HTTPS 访问域名。空间维度管理访问权限、生命周期和备份，对象前缀用于组织文件。独立域名绑定该空间，原有业务继续使用各自的空间和域名。

上传 Endpoint 和浏览器访问域名分别配置。后台对象存储选择七牛，填写正确的区域、上传 Endpoint、Bucket 和对象前缀；CDN 访问域名填写带 `https://` 的自定义域名，访问鉴权选择七牛签名。

本次沿用了账号已有域名的海外加速区域。后续部署应按域名备案、用户分布和费用选择加速区域，单独核算 CDN 流量与 HTTPS 请求费用。[七牛域名接入说明](https://developer.qiniu.com/fusion/4939/the-domain-name-to-access)

## 域名和 DNS 配置

1. 创建绑定目标私有空间的 CDN 域名，读取平台分配的 CNAME。
2. 在权威 DNS 服务商添加应用域名的 CNAME，查询权威或公共解析结果确认生效。
3. 申请证书时，按证书订单提供的主机记录和值再添加域名所有权验证记录。本次使用 `_dnsauth` 子域下的 CNAME，业务访问 CNAME 和证书验证 CNAME 各自保留。
4. 回到证书订单触发验证，同时核对 DNS 查询结果与订单中的记录值。

本次已有的阿里云 API 凭证缺少 DNS 权限，接口返回 `Forbidden.RAM`，随后使用用户授权并登录的控制台完成解析配置。后续自动化应使用专用、最小权限凭证，按操作所需授予权限。

## 证书申请和绑定

本次通过证书管理创建了价格为 0 元、有效期 90 天的单域名 DV 证书订单，使用账号已保存的联系人信息，完成 DNS 验证后等待 CA 签发。平台要求再次验证账号密码时，由用户在控制台直接完成验证。

域名创建接口接受了 HTTPS 及免费证书配置，但此时证书 ID 为空，实际 TLS 握手仍得到默认旧证书。排查应分别检查以下状态。

| 状态 | 核查内容 |
| --- | --- |
| DNS 已生效 | 业务 CNAME 和证书验证记录指向正确 |
| 域名所有权验证通过 | 证书订单展示验证通过 |
| 证书已签发 | 证书管理展示证书 ID、适用域名及有效期 |
| 证书已绑定 | 域名 HTTPS 配置引用正确证书 ID |
| 边缘节点可用 | 实际 TLS 握手校验证书域名、信任链及有效期通过 |

本次先提交证书配置，随后通过首次开启 HTTPS 接口完成开通，之后实际握手验证通过。对于首次证书配置，按平台接口语义选择 `PUT /domain/<Name>/sslize`；已有 HTTPS 配置更新使用 `PUT /domain/<Name>/httpsconf`。开通后开启强制 HTTPS，并等待实际访问验证通过再切换应用域名。[七牛域名 HTTPS 配置 API](https://developer.qiniu.com/fusion/13364/fusion-api-domain-config)

调用七牛 Python SDK 的 `DomainManager.create_domain` 时，本次使用的 SDK 版本要求传入 JSON 字符串。直接传入字典会导致服务端 JSON 解析错误，改用 `json.dumps(body)` 后创建成功。复用流程时先核对当前 SDK 的参数合同。

排查 TLS 时曾收到“证书密钥过弱”的错误，检查对端证书后确认节点返回了默认旧证书。应核对实际证书的 Subject、SAN、Issuer 和有效期，定位域名开通、证书绑定及节点同步状态，并保持客户端正常的证书校验。

## 私有鉴权和切换验收

私有空间绑定 CDN 后开启每次请求的回源鉴权，应用生成带有效期的七牛签名链接。配置切换前先用现有对象验证有效签名、未签名及过期签名，再保存应用的 CDN 配置。切换后重新获取已有资源的访问描述，核对分发方式和域名。[七牛私有空间回源鉴权说明](https://developer.qiniu.com/fusion/kb/7455/monitoring-the-source-domain-stood-seven-cows-private-bucket-suggested-that-open-source-authentication-function)

本次实际验收结果如下。

| 请求 | 结果 |
| --- | --- |
| 有效签名图片，携带 Range | `206`，`Content-Type: image/png`，`Content-Disposition: inline` |
| 未签名图片 | `401` |
| 过期签名图片 | `401` |
| 应用对象存储连接测试 | 上传、读取及清理通过 |
| 已有资源重新获取链接 | `delivery=cdn`，指向新自定义域名 |

浏览器可能仍缓存旧的 S3 签名地址。验收需要重新获取资源访问链接，检查新地址的域名及响应头；已打开标签中的旧地址也需要更新。

## 维护和敏感信息处理

本次使用的免费证书需要在到期前重新申请并替换。在证书控制台确认到期时间、通知接收方式，并为更新预留 CA 验证和节点同步时间。[七牛证书申请说明](https://developer.qiniu.com/fusion/3725/how-to-apply-for-and-use-free-certificate)

配置切换后备份数据库及必要的数据目录，同时保存加密设置所需的密钥文件；备份额外复制到独立机器。清理临时迁移明文文件。密码、访问密钥、私钥、完整签名 URL 和证书验证会话凭证均应避免进入文档、Git 和日志。
